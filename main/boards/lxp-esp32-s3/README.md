# 邻小铺 LXP · ESP32-S3-N16R8（按你这块双 Type-C 板丝印）

## USB 两个口

| 口 | 识别 | 用途 |
|----|------|------|
| 靠近 **CH343P** 芯片的那一侧 | UART | **刷机 + 串口日志**（优先） |
| 另一侧 | 原生 USB | 也可供电；一般不优先刷机 |

供电：插哪个都行；刷机优先插 **CH343 那侧**。

## 固件脚位 ↔ 板子丝印（当前正确）

**认数字，不要认 RX/TX 字样。**

| 功能 | 固件 GPIO | 你板上丝印位置 |
|------|-----------|----------------|
| 麦 WS | **1** | 右侧排针数字 **1**（在 RX 下方，不是 RX） |
| 麦 SCK | **2** | 右侧 **2** |
| 麦 SD/DIN | **42** | 右侧 **42** |
| 喇叭 DIN | **21** | USB 端附近 **21** |
| 喇叭 BCLK | **17** | 左侧 **17** |
| 喇叭 LRC | **18** | 左侧 **18** |
| 喇叭 SD | **14** | 左侧靠 5V 上方 **14** |
| 雷达 TX→板 | **16** | 左侧 **16**（**禁止接丝印 RX**） |
| 灯 / 板载 RGB | **48** | USB 端 **48**（板载 RGB 也是 48） |
| 5V / GND | — | 左侧底部 **5V / GND** |

### 容易接错

- 丝印 **RX / TX** = 接 CH343 的调试串口（约 GPIO43/44），**不是**雷达，也不是麦的 1/2。
- 雷达：模块 **TX → 丝印 16**，VCC→**5V**，GND→**GND**。
- **19 / 20** = 原生 USB，别占用。
- **35–37** 在 N16R8 上常与 Flash/PSRAM 相关，固件未用，也别私自改到这些脚。

## 喇叭 / 雷达摘要

喇叭：DIN21、BCLK17、LRC18、SD14、VIN→5V。  
雷达：TX→16、VCC→5V、GND。
